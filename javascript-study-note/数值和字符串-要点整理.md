# 数值和字符串 — 要点整理

> 来源：MDN JavaScript 指南 · 数值和字符串
> 整理日期：2026-09-14

## 概述

本章介绍 JavaScript 中最基础的两种数据类型——**数值**和**字符串**：它们的底层表示形式，以及用于处理和计算它们的函数。

## 数值

### 底层表示

- 采用 **IEEE 754 标准的 64 位双精度二进制格式**：范围约 ±10⁻³⁰⁸ 到 ±10⁺³⁰⁸（±2⁻¹⁰²² 到 ±2⁺¹⁰²³），精度 53 位；
- 整数值在 **±2⁵³ − 1** 范围内可以精确表示；
- number 类型还包含三个符号值：`Infinity`、`-Infinity` 和 `NaN`（非数值）。

### 数值字面量

四种类型：十进制、二进制、八进制、十六进制。

| 类型 | 语法 | 示例 |
| --- | --- | --- |
| 十进制 | 直接书写 | `123` |
| 二进制 | `0b` / `0B` 前缀 | `0b100 === 4` |
| 八进制 | `0o` 前缀（标准） | `0o644 === 420` |
| 十六进制 | `0x` / `0X` 前缀 | `0x8F === 143` |

注意事项：

- 十进制以 `0` 开头是**遗留的八进制语法**（0 后所有数字均小于 8 时按八进制解释）；严格模式下以 0 开头的字面量直接引发语法错误，应改用 `0o` 前缀；
- `0b` 后出现非 0/1 数字、`0x` 后超出 `0-9A-F` 范围，都会抛出 `SyntaxError`；
- **指数形式**：如 `1.79e+3`（= 1790）、`1e-3`（= 0.001）；
- **数值分隔符**：数字之间可插入下划线 `_` 提高可读性，如 `1_000_000`。

### Number 对象

内置 `Number` 对象带有数字相关的常量属性（不可改变）。**总是应从预定义的 Number 对象引用这些属性**，而不是自建的 Number 对象。

| 属性 | 描述 |
| --- | --- |
| `Number.MAX_VALUE` | 可表示的最大正数（1.7976931348623157e+308） |
| `Number.MIN_VALUE` | 可表示的最小正数（5e-324） |
| `Number.NaN` | 特殊值"非数值" |
| `Number.NEGATIVE_INFINITY` | 负无穷；溢出时返回 |
| `Number.POSITIVE_INFINITY` | 正无穷；溢出时返回 |
| `Number.EPSILON` | 1 与能表示为 Number 的最小大于 1 的值之差（2.220446049250313e-16） |
| `Number.MIN_SAFE_INTEGER` | 最小安全整数（−2⁵³ + 1） |
| `Number.MAX_SAFE_INTEGER` | 最大安全整数（+2⁵³ − 1） |

静态方法：

| 方法 | 描述 |
| --- | --- |
| `Number.parseFloat()` | 把字符串解析成浮点数（同全局 `parseFloat()`） |
| `Number.parseInt()` | 把字符串解析成特定基数的整数（同全局 `parseInt()`） |
| `Number.isFinite()` | 是否为有限数值 |
| `Number.isInteger()` | 是否为整数 |
| `Number.isNaN()` | 是否为 NaN（比全局 `isNaN()` 更稳健） |
| `Number.isSafeInteger()` | 是否为安全整数 |

原型方法（以不同格式获取数值信息）：`toExponential()`（指数表示）、`toFixed()`（定点表示）、`toPrecision()`（给定精度的定点表示）。

### Math 对象

内置 `Math` 对象提供数学常量和函数，如 `Math.PI`（π ≈ 3.141…）、`Math.sin(x)`。

- **所有三角函数都以弧度制接收参数**；
- 与其他对象不同，**永远不要自己创建 Math 对象**，总是使用内置的。

| 方法 | 描述 |
| --- | --- |
| `abs()` | 绝对值 |
| `sin()` `cos()` `tan()` | 标准三角函数（弧度制参数） |
| `asin()` `acos()` `atan()` `atan2()` | 反三角函数（返回弧度值） |
| `sinh()` `cosh()` `tanh()` | 双曲函数 |
| `asinh()` `acosh()` `atanh()` | 反双曲函数 |
| `pow()` `exp()` `expm1()` `log()` `log10()` `log1p()` `log2()` | 指数与对数函数 |
| `floor()` `ceil()` | 小于/大于等于参数的最大/最小整数 |
| `min()` `max()` | 参数列表中的最小/最大值 |
| `random()` | 0 到 1 之间的随机数 |
| `round()` `fround()` `trunc()` | 舍入和截断 |
| `sqrt()` `cbrt()` `hypot()` | 平方根、立方根、平方和的平方根 |
| `sign()` | 数字的符号（正/负/零） |
| `clz32()` `imul()` | 32 位前导零计数；C 风格 32 位乘法 |

### BigInt

- 数值只有 64 位，**无法精确表示大于 `Number.MAX_SAFE_INTEGER`（2⁵³ − 1）的整数**；
- `BigInt` 用于表示**任意大整数**，满足二进制数据编码及与其他语言 i64/i128 互操作的需求。

两种创建方式：

```js
const a = 10n;            // 以 n 结尾的整数字面量
const b = BigInt("9000"); // BigInt 构造函数（数字或字符串）
```

要点：

- 任意长度位序列，可安全进行算术运算，**不丢失精度、不溢出/下溢**；
- **无法表示浮点数**，除法结果向零截断：`7n / 2n === 3n`；
- **Math 函数不能用于 BigInt**，仅适用于数字；
- 选型：日常任务数字精度通常够用，BigInt 最适合处理二进制数据和大整数。

## 字符串

### 底层表示

字符串用于表示文本数据，是一组 **16 位无符号整数值（UTF-16 码元）** 组成的"元素"序列：

- 每个元素占据一个位置，第一个元素索引为 0，依次递增；
- 字符串的**长度 = 元素数量**；
- 可通过字符串字面量或字符串对象创建。

### 字符串字面量

用**单引号或双引号**声明。大多数字符可直接输入，例外有三个：

1. 反斜杠 `\`（用于开始转义序列）；
2. 包围字符串的引号（会提前结束字符串）；
3. 换行符（前面不加反斜杠会导致语法错误）。

常用转义序列：

| 转义 | 含义 |
| --- | --- |
| `\0` | 空字节 |
| `\b` `\f` `\v` | 退格、换页、垂直制表 |
| `\n` `\r` `\t` | 换行、回车、水平制表 |
| `\'` `\"` `\\` | 单引号、双引号、反斜杠 |
| `\xXX` | 十六进制转义（`\x` 后按十六进制解释） |
| `\uXXXX` | Unicode 转义（`\u` 后至少 4 个十六进制数字） |
| `\u{X…X}` | Unicode 码位转义（最高支持 0x10FFFF） |

> 码位转义 `\u{...}` 可以表示任何字符；四位数的 `\uXXXX` 转义表示超出基本平面的字符时，需要分别写出两个代理字符。参见 `String.fromCodePoint()` / `String.prototype.codePointAt()`。

### String 对象：字符串值上的方法

可以直接在字符串值上调用方法，按功能分五类：

| 类别 | 方法 | 作用 |
| --- | --- | --- |
| 查询 | `at()` `charAt()` `charCodeAt()` `codePointAt()` | 获取特定索引处的字符或字符编码 |
| 搜索 | `indexOf()` `lastIndexOf()` `startsWith()` `endsWith()` `includes()` `match()` `matchAll()` `search()` | 查找符合模式的子串 / 检测子串是否存在 |
| 组合 | `padStart()` `padEnd()` `concat()` `repeat()` | 组合成更长的字符串 |
| 分解 | `split()` `slice()` `substring()` `substr()` `trim()` `trimStart()` `trimEnd()` | 拆分为较短的字符串 |
| 转换 | `toLowerCase()` `toUpperCase()` `toLocaleLowerCase()` `toLocaleUpperCase()` `normalize()` `toWellFormed()` | 根据内容返回新字符串 |

另外两个重要对象：**RegExp**（正则表达式）和 **Intl**（国际化），分别提供模式匹配和区域化字符串处理能力。

### 模板字面量

模板字面量是**允许嵌入表达式**的字符串字面量，支持多行字符串和字符串插值：

- 用**反引号 `` ` ``** 包围（代替单/双引号）；
- 占位符写法：**`${表达式}`**。

**多行文本**：源代码中插入的换行符直接属于模板字面量的一部分：

```js
// 普通字符串需要显式 \n
"第一行\n第二行";

// 模板字面量直接换行
`第一行
第二行`;
```

**嵌入表达式**：

```js
// 普通字符串拼接
"你好，" + name + "，你今年 " + (age + 1) + " 岁。";

// 模板字面量插值，更易读
`你好，${name}，你今年 ${age + 1} 岁。`;
```

## 速记卡片

| 主题 | 一句话要点 |
| --- | --- |
| 数值底层 | IEEE 754 双精度 64 位；±2⁵³−1 内整数精确；特殊值 `Infinity` `-Infinity` `NaN` |
| 字面量前缀 | 二进制 `0b`、八进制 `0o`（严格模式禁旧式 `0` 前缀）、十六进制 `0x`；`_` 分隔符提高可读性 |
| Number | 常量属性从内置对象取；`is*` 系列判断有限/整数/NaN/安全整数；`toFixed` `toPrecision` `toExponential` 格式化 |
| Math | 三角函数收弧度；永远用内置 Math 对象，不要自建 |
| BigInt | 字面量加 `n` 或 `BigInt()`；任意精度但无浮点，除法向零截断；Math 函数不可用 |
| 字符串底层 | UTF-16 码元序列；索引从 0 开始；长度 = 元素数 |
| 转义 | `\x` 十六进制、`\u` 四位 Unicode、`\u{}` 码位（支持到 0x10FFFF） |
| 方法五类 | 查询 / 搜索 / 组合 / 分解 / 转换；另有 RegExp 与 Intl |
| 模板字面量 | 反引号包围；`${}` 插值；换行即多行 |
