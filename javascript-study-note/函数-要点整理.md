# 函数 - 要点整理

> 来源：[MDN - JavaScript 指南 / 函数](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Guide/Functions)

---

## 一、函数的定义方式

### 1. 函数声明（Function Declaration）
- 使用 `function` 关键字
- **会被提升（Hoisting）**：可在声明之前调用

```javascript
function square(number) {
  return number * number;
}
console.log(square(5)); // 25
```

### 2. 函数表达式（Function Expression）
- 将函数赋值给变量，可匿名或具名
- **不会被提升**：必须在定义之后才能调用

```javascript
const square = function (number) {
  return number * number;
};
```

### 3. 箭头函数（Arrow Function）
- 语法简洁
- **没有自己的 `this`、`arguments`、`super`、`new.target`**
- 适合回调、map/filter/reduce 等场景

```javascript
const a = ["Hydrogen", "Helium"];
const lengths = a.map((s) => s.length); // [8, 6]
```

### 对比速查

| 特性 | 函数声明 | 函数表达式 | 箭头函数 |
|------|---------|-----------|---------|
| 提升 | ✅ | ❌ | ❌ |
| 自有 this | ✅ | ✅ | ❌（继承外层） |
| 可作构造函数 | ✅ | ✅ | ❌ |
| arguments 对象 | ✅ | ✅ | ❌ |

## 二、函数参数

### 默认参数
未传值或传入 `undefined` 时使用默认值：

```javascript
function multiply(a, b = 1) {
  return a * b;
}
multiply(5);    // 5
multiply(5, 2); // 10
```

### 剩余参数（Rest Parameters）
用 `...` 将不定数量的参数收集为**真正的数组**：

```javascript
function multiply(multiplier, ...theArgs) {
  return theArgs.map((x) => multiplier * x);
}
multiply(2, 1, 2, 3); // [2, 4, 6]
```

### arguments 对象
类数组对象，包含所有实际传入的参数（箭头函数中不可用）：

```javascript
function myConcat(separator) {
  let result = "";
  for (let i = 1; i < arguments.length; i++) {
    result += arguments[i] + separator;
  }
  return result;
}
```

> 💡 现代写法优先使用**剩余参数**代替 `arguments`。

## 三、作用域与闭包

### 作用域链
- 函数内变量对外不可见
- 内部函数可以访问外部函数的变量和参数
- 层层嵌套形成**作用域链**

### 闭包（Closure）
内部函数**保留对外部作用域的引用**，即使外部函数已执行完毕：

```javascript
const createPet = function (name) {
  let sex; // 私有变量
  return {
    setName(newName) { name = newName; },
    getName() { return name; },
    setSex(newSex) { sex = newSex; }
  };
};

const pet = createPet("Vivie");
pet.setName("Oliver");
console.log(pet.getName()); // "Oliver"
```

> ⚠️ **闭包命名冲突陷阱**：内部函数定义了与外部同名的变量/参数时，内部变量会遮蔽（shadow）外部变量。

### 递归
函数调用自身，必须有终止条件：

```javascript
function factorial(n) {
  if (n === 0 || n === 1) return 1;
  return n * factorial(n - 1);
}
```

## 四、高阶函数

函数是一等公民，可以作为参数传递：

```javascript
function map(f, a) {
  const result = new Array(a.length);
  for (let i = 0; i < a.length; i++) {
    result[i] = f(a[i]);
  }
  return result;
}

const cube = (x) => x * x * x;
map(cube, [0, 1, 2]); // [0, 1, 8]
```

## 五、this 关键字

### 传统函数的 this
每次调用时动态确定，取决于**调用方式**而非定义位置。

### 箭头函数的 this
没有自己的 `this`，**词法继承**外层作用域的 `this`：

```javascript
function Person() {
  this.age = 0;
  setInterval(() => {
    this.age++; // ✅ this 指向 Person 实例
  }, 1000);
}
```

### call / apply / bind

| 方法 | 作用 | 区别 |
|------|------|------|
| `call(thisArg, arg1, arg2...)` | 立即调用，指定 this | 参数逐个传入 |
| `apply(thisArg, [args])` | 立即调用，指定 this | 参数以数组传入 |
| `bind(thisArg, arg1...)` | **返回新函数**，this 永久绑定 | 不立即执行 |

## 七、重点解析：`outside()(10)` 的执行过程

```javascript
function outside() {
  const x = 5;          // ① 外部函数的 x = 5
  function inside(x) {  // ② inside 有自己的参数 x（遮蔽了外部的 x）
    return x * 2;
  }
  return inside;         // ③ 返回 inside 函数本身（不是调用结果）
}

console.log(outside()(10)); // 20
```

### 逐步拆解

这个表达式看起来奇怪，是因为它把**两步调用**写在了同一行。拆开看就清楚了：

```javascript
// 等价于：
const fn = outside();   // 第一步：调用 outside()，返回值是 inside 函数
const result = fn(10);  // 第二步：调用返回的 inside 函数，传入 10
console.log(result);     // 20
```

### 关键理解点

| 步骤 | 发生了什么 | 结果 |
|------|-----------|------|
| `outside()` | 执行 outside 函数体，走到 `return inside` | 得到 **inside 函数本身**（一个函数对象） |
| `(10)` | 对上一步得到的函数对象进行调用，传入参数 10 | inside(10) → 10 × 2 = **20** |

### 为什么结果是 20 而不是 10？

- `inside` 的参数 `x` **遮蔽（shadow）** 了外部的 `const x = 5`
- 所以 `inside(10)` 中的 `x` 是传入的 `10`，不是外部的 `5`
- `10 * 2 = 20`

### 如果去掉 inside 的参数呢？

```javascript
function outside() {
  const x = 5;
  function inside() {   // 没有自己的 x 了
    return x * 2;       // 这里的 x 来自外部作用域 → 闭包
  }
  return inside;
}

console.log(outside()(10)); // 10 ← 注意！传入的 10 被忽略了
// 因为 inside() 不接受参数，x 始终是闭包捕获的 5，5 * 2 = 10
```

> 💡 **核心要点**：`outside()` 返回的是一个**函数**，不是数值。`outside()(10)` 本质上是「先拿到函数，再立刻调用它」。这是 JavaScript 中**高阶函数**和**闭包**的经典模式。
