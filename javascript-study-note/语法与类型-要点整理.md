## 语法与类型 — MDN JavaScript 指南要点整理

> 来源：MDN《JavaScript 指南 — 语法与类型》
> 本章涵盖：基本语法、变量声明、数据类型、字面量

### 一、基础语法

- **区分大小写**，使用 Unicode 字符集：可用 `Früh` 作变量名，且 `früh` 与 `Früh` 是两个不同变量。
- 指令称为**语句**，用分号（`;`）分隔。语句独占一行时分号可省略（ASI 自动插入分号），但最佳实践是**始终加分号**。
- 源码从左往右扫描，转换为输入元素序列：token、控制字符、行终止符、注释、空白字符。

### 二、注释

- `//` 单行注释；`/* ... */` 块注释，**块注释不能嵌套**（注释中意外出现 `*/` 会提前结束注释，可用反斜杠破坏该模式）。
- 文件开头的 `#!/usr/bin/env node` 是 **hashbang 注释**，用于指定执行脚本的引擎路径。

### 三、声明

三种变量声明方式：

| 关键字 | 说明 |
|---|---|
| `var` | 声明变量（可选初始化），作用域为全局或函数，取决于上下文 |
| `let` | 块级作用域的局部变量（可选初始化） |
| `const` | 块级作用域的只读常量 |

此外可用**解构语法**声明变量，如 `const { bar } = foo`，从对象中解包同名属性赋值。

#### 标识符规则

- 以字母、下划线 `_` 或美元符号 `$` 开头，后续字符可为数字。
- 支持大部分 Unicode 字母。合法示例：`Number_hits`、`temp99`、`$credit`、`_name`。

#### 声明与初始化

- `let x = 42` 中，`let x` 是声明，`= 42` 是初始化器；等价于 `let x; x = 42;`。
- `var`/`let` 可不初始化，默认值为 `undefined`；`const` **必须初始化**。
- 应先声明后使用；给未声明的变量赋值会创建"未声明的全局变量"，严格模式下报错，应彻底避免。

#### 变量作用域

- 全局作用域、模块作用域、函数作用域；`let`/`const` 另有**块级作用域**（一对花括号）。
- 函数外声明的是全局变量，函数内声明的是局部变量。
- `var` 创建的变量**不是块级作用域**，只属于所在函数（或全局）。

#### 变量提升

- `var` 声明会被提升：可在声明前引用，但值为 `undefined`——只有声明和默认初始化被提升，赋值不被提升。建议 `var` 语句尽量靠近函数顶部。
- `let`/`const`：在声明之前引用会抛 `ReferenceError`，变量处于从块开始到声明处的**暂时性死区**。
- 函数声明是**全部提升**，可在作用域任意位置安全调用。

#### 全局变量

- 全局变量是全局对象的属性：网页中为 `window`，可用 `window.variable` 读写；所有环境统一用 `globalThis`。
- 可通过窗口名跨窗口访问变量，如 iframe 中用 `parent.phoneNumber`。

#### 常量

- `const` 创建只读命名常量：不可通过赋值改变、不可重新声明、必须初始化，作用域规则同 `let`。
- 同一作用域中，常量不能与变量或函数同名。
- `const` **只阻止重新赋值，不阻止修改**：常量对象的属性、数组的元素仍可修改。

### 四、数据结构和类型

#### 8 种数据类型

七种基本类型 + Object：

1. `Boolean`：`true` / `false`
2. `null`：表示空值的特殊关键字（区分大小写）
3. `undefined`：未定义的值
4. `Number`：整数或浮点数，如 `42`、`3.14159`
5. `BigInt`：任意精度整数，如 `9007199254740992n`
6. `String`：文本值的字符序列
7. `Symbol`：实例唯一且不可变
8. `Object`

函数技术上是一种对象，但可视为语言的基本元素：对象是存放值的命名容器，函数是程序能执行的过程。

#### 类型转换

- JavaScript 是**动态类型语言**：声明变量不必指定类型，运行时按需自动转换。
- `+` 运算符：表达式中数字与字符串相加时，数字被转换成字符串；其他运算符不做此转换。
- 字符串转数字的方法：`parseInt()`（最佳实践是**总是传进制参数**）、`parseFloat()`、一元 `+` 运算符。`parseInt` 只返回整数。

### 五、字面量

#### 数组字面量

- `[]` 包裹的零个或多个表达式列表，创建数组时以指定值初始化，`length` 等于参数个数。
- 每次求值都会创建新的数组对象。
- **多余逗号**：连续两个逗号留下"空槽"——空槽被 `map` 等遍历方法跳过，但索引访问返回 `undefined`；列表尾部的逗号被忽略（利于 git diff 整洁）。
- 建议显式将缺失元素声明为 `undefined` 或加注释，提高可维护性。

#### 布尔字面量

- `true` 和 `false`；不要将原始布尔值与 `Boolean` 对象的真/假混淆。

#### 数字字面量

- 整数字面量支持四种进制：十进制（无前缀）、八进制（`0`/`0O`/`0o`）、十六进制（`0x`）、二进制（`0b`）。
- `BigInt` 由整数字面量加后缀 `n`，支持各进制；注意 `0123n` 不允许，但 `0o123n` 可以。
- 浮点数字面量语法：`[digits].[digits][(E|e)[(+|-)]digits]`，至少一位数字且必须有小数点或 `e`。
- 规范要求数字字面量无符号，`-123.4` 实为一元 `-` 作用于 `123.4`。

#### 对象字面量

- `{}` 包裹的属性名-值列表；**不能在语句开头使用对象字面量**（`{` 会被当作语句块的开始）。
- 属性名可以是字符串（含空串）或数字；不合法的标识符名须加引号，且只能用方括号 `[]` 访问，不能用点 `.`。
- **增强的对象字面量**：支持设置原型、`foo: foo` 简写、方法定义、`super` 调用、表达式计算属性名，使对象字面量与类声明更紧密。

#### RegExp 字面量

- 正则表达式字面量：字符被正斜杠围成，如 `/ab+c/`。

#### 字符串字面量

- 一对双引号或单引号包裹的零个或多个字符，必须成对同种引号。建议统一用双引号。
- 优先使用字符串字面量而非 `String` 对象；字面量上可直接调用 `String` 方法（自动转为临时对象再废弃）。
- **模板字面量**：反引号 `` ` `` 包围，提供字符串插值语法糖；**带标签的模板**是调用标签函数解析模板的紧凑语法（标签函数名写在模板前面）。
- 特殊字符转义：`\0` 空字节、`\b` 退格、`\f` 换页、`\n` 换行、`\r` 回车、`\t` 制表、`\v` 垂直制表、`\'`、`\"`、`\\`，以及 `\XXX`（八进制 Latin-1）、`\xXX`（十六进制 Latin-1）、`\uXXXX`（Unicode）、`\u{XXXXX}`（Unicode 码位）。
- 引号转义：引号前加反斜杠；反斜杠本身需写成 `\\`；行尾反斜杠可转义换行（反斜杠和换行都不出现在值中）。
