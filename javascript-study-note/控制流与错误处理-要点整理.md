# 控制流与错误处理 — 要点整理

> 来源：MDN JavaScript 指南 · 控制流与错误处理
> 整理日期：2026-08-30

JavaScript 用一套小巧的语句（尤其是控制流语句）实现程序的交互逻辑。语句之间用分号 `;` 分隔，表达式本身也可以作为语句。

---

## 一、块语句

块语句是最基本的语句，用于把多条语句组合在一起，由一对花括号 `{ }` 界定，常与 `if`、`for`、`while` 等控制流语句搭配使用。

```js
if (condition) {
  x++;   // { x++; } 就是块语句
}
```

**作用域要点（易错点）：**

- `var` 声明的变量**不是块级作用域**，而是函数作用域或脚本作用域，效果会超出块本身：

```js
var x = 1;
{
  var x = 2;
}
console.log(x); // 输出 2（块内外的 var x 作用域相同）
```

- 使用 `let` 或 `const` 则是块级作用域，同样的代码会输出 `1`。

---

## 二、条件语句

条件语句在指定条件为真时执行指令。JavaScript 支持两种：`if...else` 和 `switch`。

### 1. if...else

- `if`：条件为 `true` 时执行语句；
- `else`（可选）：条件为 `false` 时执行；
- `else if`：按顺序测试多个条件，**只有第一个求值为 `true` 的条件会被执行**。

**最佳实践：**

1. 总是使用块语句包裹要执行的语句，嵌套 `if` 时尤其如此；
2. 最好不要把赋值（如 `x = y`）作为 `if` 的条件，避免与比较混淆。

**假值（falsy values）——以下值求值为 `false`：**

| 假值 |
| --- |
| `false` |
| `undefined` |
| `null` |
| `0` |
| `NaN` |
| 空字符串 `""` |

其余所有值（包括一切对象）在条件判断中都求值为 `true`。

> 注意：不要混淆原始布尔值 `true` / `false` 与 `Boolean` 对象的真和假。`new Boolean(false)` 作为对象，求值结果是 `true`。

### 2. switch

`switch` 求表达式的值，并与 `case` 标签匹配，匹配成功则执行相关语句。

执行流程：

1. 查找与表达式值匹配的 `case` 标签，找到则转移控制权执行对应语句；
2. 没有匹配时，查找可选的 `default` 子句并执行；
3. 既无匹配也无 `default`，直接继续执行 `switch` 后面的语句。

**break 语句：**

- 每个 `case` 后可选 `break`，保证匹配执行完后跳出 `switch`；
- 省略 `break` 会发生"贯穿"（fall-through）：继续执行下一个 `case` 的语句。

```js
switch (fruitType) {
  case "Bananas":
    console.log("香蕉");
    break;            // 不写则会继续执行下面 case 的语句
  case "Cherries":
    console.log("樱桃");
    break;
  default:
    console.log("未知水果");
}
```

> `default` 通常写在最后，但位置不是强制的。

## 三、异常处理语句

用 `throw` 抛出异常，用 `try...catch` 处理异常。

### 1. throw 语句

- 可以抛出**任意表达式**（数字、字符串、对象等）；
- 但更推荐使用专门为错误设计的异常类型，如 **ECMAScript 异常**（`Error`、`TypeError` 等）和 **DOMException**。

### 2. try...catch 语句

- `try` 块：标记可能抛出异常的代码；
- `catch` 块：`try` 中抛出异常时执行的代码；
- 异常一旦抛出，控制立即转移到 `catch`；没有异常则跳过 `catch`。

```js
try {
  monthName = getMonthName(month); // 月份无效时抛异常
} catch (exception) {
  monthName = "未知";   // exception 标识符只在 catch 块存续期间存在
}
```

**catch 块要点：**

- `catch (exception)` 中的标识符保存抛出的值，可用来获取异常信息；
- 该标识符在进入 `catch` 时创建，`catch` 执行完即失效；
- 在 `catch` 中输出错误建议用 `console.error()` 而非 `console.log()`，它会以错误格式输出并加入页面的错误列表。

### 3. finally 块

- 在 `try` 和 `catch` 之后、`try...catch` 后续语句之前执行；
- **无论是否抛出异常都会执行**（即使没有 `catch` 处理）；
- 常用于优雅退出：释放资源、关闭文件等，保证出错时资源也不会泄漏；
- 若 `finally` 中有返回值，它会**覆盖** `try` / `catch` 中的 `return` 值；同样可以覆盖 `catch` 内抛出或重新抛出的异常流程。

### 4. 嵌套 try...catch

- 可以嵌套一个或多个 `try...catch`；
- 内层 `try` 如果没有对应的 `catch` 块，则**必须有 `finally` 块**，异常会交给外层 `try...catch` 的 `catch` 检查处理。

### 5. 使用 Error 对象

- `name` 属性：给出错误类的一般信息（如 `DOMException`、`Error`）；
- `message` 属性：通常比把错误对象转成字符串得到的信息更精炼；
- 抛出自定义异常时，建议使用 `Error` 构造函数（如 `throw new Error("…")`），以便充分利用这两个属性，也便于 `catch` 区分自定义异常和系统异常。

## 速记卡片

| 主题 | 关键结论 |
| --- | --- |
| 块作用域 | `var` 无块作用域，`let` / `const` 有 |
| 假值 | `false`、`undefined`、`null`、`0`、`NaN`、`""` |
| if 多条件 | 只有第一个为真的 `else if` 分支被执行 |
| switch | 无 `break` 会贯穿到下一个 `case` |
| try...catch | 异常立即转入 `catch`；catch 标识符仅在块内存活 |
| finally | 有无异常都执行，返回值会覆盖 try/catch 的 return |
| 自定义异常 | 用 `new Error()`，善用 `name` 和 `message` |
