# 表达式与运算符 — 要点整理

> 来源：MDN JavaScript 指南 · 表达式与运算符
> 整理日期：2026-09-14

## 概述

本章涵盖 JavaScript 的表达式和运算符：赋值、比较、算术、位运算、逻辑、字符串、三元等。

按操作数个数分类：

- **二元运算符**：需要两个操作数，分别在运算符前后，如 `3+4`、`x*y`；
- **一元运算符**：需要一个操作数，在运算符前或后，如 `++x`、`x++`；
- **三元运算符**：只有一个——条件（三元）运算符 `? :`。

## 赋值运算符

赋值运算符把右边操作数的值赋给左边操作数，最基本的是 `=`（`x = y`）。

复合赋值运算符是运算+赋值的简写：

| 名字 | 简写 | 含义 |
| --- | --- | --- |
| 加法赋值 | `x += y` | `x = x + y` |
| 减法赋值 | `x -= y` | `x = x - y` |
| 乘法赋值 | `x *= y` | `x = x * y` |
| 除法赋值 | `x /= y` | `x = x / y` |
| 求余赋值 | `x %= y` | `x = x % y` |
| 求幂赋值 | `x **= y` | `x = x ** y` |
| 左移位赋值 | `x <<= y` | `x = x << y` |
| 右移位赋值 | `x >>= y` | `x = x >> y` |
| 无符号右移位赋值 | `x >>>= y` | `x = x >>> y` |
| 按位与赋值 | `x &= y` | `x = x & y` |
| 按位异或赋值 | `x ^= y` | `x = x ^ y` |
| 按位或赋值 | `x \|= y` | `x = x \| y` |
| 逻辑与赋值 | `x &&= f()` | `x && (x = f())` |
| 逻辑或赋值 | `x \|\|= f()` | `x \|\| (x = f())` |
| 逻辑空赋值 | `x ??= f()` | `x ?? (x = f())` |

**解构**：对于更复杂的赋值，解构语法可以从数组/对象中按对应结构直接提取数据。

## 比较运算符

比较操作数并返回逻辑值。字符串比较基于标准字典顺序（Unicode 值）；两边类型不同时，JavaScript 通常会先转换类型再比较——**例外是 `===` 和 `!==`，它们不做类型转换（严格比较）**。

| 运算符 | 描述 | 返回 true 的示例 |
| --- | --- | --- |
| 等于 `==` | 两边操作数相等 | `3 == var1`、`"3" == var1`、`3 == '3'` |
| 不等于 `!=` | 两边操作数不相等 | `var1 != 4`、`var2 != "3"` |
| 全等 `===` | 相等且类型相同 | `3 === var1` |
| 不全等 `!==` | 不相等或类型不同 | `var1 !== "3"`、`3 !== '3'` |
| 大于 `>` | 左 > 右 | `var2 > var1`、`"12" > 2` |
| 大于等于 `>=` | 左 ≥ 右 | `var2 >= var1` |
| 小于 `<` | 左 < 右 | `var1 < var2`、`"2" < 12` |
| 小于等于 `<=` | 左 ≤ 右 | `var1 <= var2` |

> 备注：`=>` 不是运算符，而是箭头函数的标记符号。

## 算术运算符

以数值为操作数并返回数值。标准的 `+ - * /` 对浮点数的表现与其他语言一致（**除零会产生 `Infinity`**）。

| 运算符 | 描述 | 示例 |
| --- | --- | --- |
| 求余 `%` | 返回相除后的余数 | `12 % 5` → `2` |
| 自增 `++` | 值加一；前缀 `++x` 返回加一后的值，后缀 `x++` 返回原值再加一 | `x=3; ++x` → 4；`y=3; y++` → 3（之后 y 为 4） |
| 自减 `--` | 值减一；前后缀规则同自增 | `x=3; --x` → 2 |
| 一元负值 `-` | 返回操作数的负值 | `-x` → `-3` |
| 一元正值 `+` | 操作数不是数值时尝试转换为数值 | `+'3'` → `3`；`+true` → `1` |
| 指数 `**` | 底数的指数次方 | `2 ** 3` → `8`；`10 ** -1` → `0.1` |

## 位运算符

位运算符把操作数视为 **32 位二进制串**（超过 32 位则取低 32 位）进行运算，返回标准 JavaScript 数值。

| 运算符 | 用法 | 描述 |
| --- | --- | --- |
| 按位与 AND | `a & b` | 对应位都为 1 才得 1 |
| 按位或 OR | `a \| b` | 对应位有一个为 1 就得 1 |
| 按位异或 XOR | `a ^ b` | 对应位不相同得 1，相同得 0 |
| 按位非 NOT | `~a` | 反转所有位（最高位为 1 表示负数，2-补码） |
| 左移 | `a << b` | 向左移 b 位，右边补 0 |
| 算术右移 | `a >> b` | 向右移 b 位，左边用原符号位补齐 |
| 无符号右移 | `a >>> b` | 向右移 b 位，左边一律补 0 |

示例（15 = `1111`，9 = `1001`）：

| 表达式 | 结果 | 二进制描述 |
| --- | --- | --- |
| `15 & 9` | 9 | `1111 & 1001 = 1001` |
| `15 \| 9` | 15 | `1111 \| 1001 = 1111` |
| `15 ^ 9` | 6 | `1111 ^ 1001 = 0110` |
| `~15` | -16 | 全部 32 位取反 |
| `9 << 2` | 36 | `1001` → `100100` |
| `9 >> 2` | 2 | `1001` → `10`；`-9 >> 2` → `-3`（符号保留） |
| `19 >>> 2` | 4 | `10011` → `100`；对非负数与 `>>` 结果相同 |

## 逻辑运算符

常用于布尔值，但 `&&` 和 `||` 实际返回的是**某个特定操作数的值**，用于非布尔值时返回值也可能不是布尔值。

| 运算符 | 范例 | 描述 |
| --- | --- | --- |
| 逻辑与 `&&` | `expr1 && expr2` | expr1 能转换为 false 则返回 expr1，否则返回 expr2 |
| 逻辑或 `\|\|` | `expr1 \|\| expr2` | expr1 能转换为 true 则返回 expr1，否则返回 expr2 |
| 逻辑非 `!` | `!expr` | 操作数能转换为 true 则返回 false，否则返回 true |

能被转换为 false 的值（falsy）：`null`、`0`、`NaN`、空字符串 `""`、`undefined`。

**短路求值**（从左到右求值，短路部分不会被求值、无副作用）：

```js
false && anything // 短路求值为 false
true || anything  // 短路求值为 true
```

## 字符串运算符

- 连接运算符 `+`：连接两个字符串，返回拼接后的新字符串；
- 简写 `+=` 也可用于拼接字符串。

## 条件（三元）运算符

JavaScript 中**唯一需要三个操作数**的运算符，根据条件在两个值中取其一：

```js
条件 ? 值1 : 值2
// 例：age >= 18 ? "adult" : "minor"
```

可在任何允许使用标准运算符的地方使用。

## 逗号运算符

`(`,`)` 对两个操作数求值并**返回最后一个操作数的值**。常用在 `for` 循环中，每次循环同时更新多个变量（如遍历二维数组对角线时同时移动行列下标）。

## 一元运算符

### delete

删除对象的属性或数组中的某个元素：

- 删除成功返回 `true`，不成功返回 `false`；删除后属性/元素变为 `undefined`；
- 可删除各种隐式声明的变量，但**不能删除 `var` 声明的变量**；
- 删除数组元素后**数组长度不变**，`trees[3]` 仍可寻址但返回 `undefined`；
- 若只想让元素值为 `undefined` 而保留元素，应直接赋值 `undefined` 而不是用 `delete`。

### typeof

返回一个表示操作数类型的**字符串**。操作数可以是字符串、变量、关键词或对象，两侧括号可选：

```js
typeof operand
typeof (operand)
```

### void

表明一个运算**没有返回值**。典型用法是超链接中阻止跳转：

```html
<a href="javascript:void(0)">点击无效果</a>
```

## 关系运算符

对操作数进行比较，返回相应布尔值。

- **`in`**：指定的属性（或数组索引）存在于指定对象中则返回 `true`；
- **`instanceof`**：判别的对象确实是指定类型（如 `Date`、`Array`）则返回 `true`。需要在运行时确认对象类型时使用，例如 `catch` 异常时按抛出异常的类型分别处理。

## 运算符优先级

优先级决定表达式的计算顺序；**不确定时用括号 `()` 显式声明**。从高到低：

| 优先级 | 运算符类型 | 个别运算符 |
| --- | --- | --- |
| 1（最高） | 成员访问 | `.` `[]` |
| 2 | 调用 / 创建实例 | `()` `new` |
| 3 | 取反 / 自增自减 | `!` `~` `-` `+` `++` `--` `typeof` `void` `delete` |
| 4 | 乘除余 | `*` `/` `%` |
| 5 | 加减 | `+` `-` |
| 6 | 位移 | `<<` `>>` `>>>` |
| 7 | 关系 | `<` `<=` `>` `>=` `in` `instanceof` |
| 8 | 相等 | `==` `!=` `===` `!==` |
| 9 | 按位与 | `&` |
| 10 | 按位异或 | `^` |
| 11 | 按位或 | `\|` |
| 12 | 逻辑与 | `&&` |
| 13 | 逻辑或 | `\|\|` |
| 14 | 条件 | `?:` |
| 15 | 赋值 | `=` `+=` `-=` `*=` `/=` `%=` `<<=` `>>=` `>>>=` `&=` `^=` `\|=` |
| 16（最低） | 逗号 | `,` |

## 表达式

表达式是一组代码的集合，**返回一个值**。概念上分两种：

1. **有副作用的**：如 `x = 7`（用 `=` 把 7 赋给 x，表达式自身的值也是 7）；
2. **单纯计算求值的**：如 `3 + 4`（求出 7 但不赋值给变量）。

表达式的类型：算数（得出数字）、字符串（得出字符串）、逻辑值（得出 true/false）、基本表达式、左值表达式。

### 基本表达式

- **`this`**：指代当前对象，通常是方法中正在被调用的对象（如在表单元素的 `onchange` 处理函数中用 `this` 指代当前表单元素）；
- **分组运算符 `()`**：控制表达式中的计算优先级，例如改变"先乘除后加减"的顺序；
- **数值推导（Comprehensions）**：实验性、非标准特性，形如 `[for (x of y) x]`，用已有数组快速创建新数组（标准化前景不明，推荐改用生成器函数等替代）。

### 左值表达式

左值可以作为赋值的目标。

- **`new`**：创建自定义类型或预置类型的对象实例，`new constructor([args])`；
- **`super`**：调用对象父类的函数，调用父类构造函数时特别有用：

```js
super([arguments]);              // 调用父类构造函数
super.functionOnParent([arguments]);
```

| 主题 | 一句话要点 |
| --- | --- |
| 赋值 | `=` 及复合赋值；`&&=` `\|\|=` `??=` 是逻辑赋值 |

| 位运算 | 操作数按 32 位二进制运算；`>>>` 左补 0，`>>` 补符号位 |
| 逻辑 | `&&` `\|\|` 返回操作数本身而非布尔值；falsy：`null` `0` `NaN` `""` `undefined`；短路求值 |
| 三元 | `条件 ? 值1 : 值2`，唯一的三元运算符 |
| 逗号 | 求值两个操作数，返回最后一个 |
| delete | 不能删 `var` 变量；删数组元素长度不变、值成 `undefined` |
| in / instanceof | `in` 查属性是否存在；`instanceof` 查对象类型 |
| 优先级 | 成员访问最高，逗号最低；不确定就加括号 |
| 表达式 | 返回值的代码；分有副作用与纯求值两类 |
| this / new / super | `this` 指当前对象；`new` 建实例；`super` 调父类 |
