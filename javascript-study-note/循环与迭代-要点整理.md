# 循环与迭代 — 要点整理

> 来源：MDN JavaScript 指南 · 循环与迭代
> 整理日期：2026-08-30

## 概述

循环提供了一种快速、简单的方式来重复执行一段代码（重复次数也可能为 0）。各种循环机制本质上做的都是同一件事，区别在于确定循环开始和结束的方式不同，因此在不同场景下某种循环会更简洁好用。

JavaScript 提供的循环语句：`for`、`do...while`、`while`、`label`、`break`、`continue`、`for...in`、`for...of`。

## for 语句

`for` 循环会一直重复执行，直到指定的循环条件为 `false`，与 Java、C 的 `for` 循环非常相似。

执行过程分四步：

1. 执行初始化表达式 `initialization`（通常初始化一个或多个计数器，也可以声明变量）；
2. 计算条件表达式 `condition`：为 `true` 则执行循环体，为 `false` 则终止循环；若 `condition` 整个被省略，则视为 `true`（慎用，可能导致死循环）；
3. 执行循环体 `statement`（多条语句用 `{ ... }` 包裹）；
4. 执行更新表达式 `afterthought`，然后回到第 2 步。

```js
for (let i = 0; i < select.options.length; i++) {
  if (select.options[i].selected) {
    count++;
  }
}
```

## do...while 语句

`do...while` 循环重复执行，直到条件求值为 `false`。

与 `while` 的关键区别：**循环体会先执行一次，然后再检查条件**，因此循环至少会执行一次。

```js
let i = 0;
do {
  console.log(i);
  i++;
} while (i < 5); // 至少重复一次，直到 i 不再小于 5
```

## while 语句

只要条件求值为 `true`，`while` 就一直执行语句块；**条件检测发生在每次执行语句之前**。条件变为 `false` 时，控制权交回 `while` 后面的代码。

```js
let n = 0, x = 0;
while (n < 3) {
  n++;
  x += n;
}
// 每轮变化：第一轮后 n=1, x=1；第二轮后 n=2, x=3；第三轮后 n=3, x=6
// 此后 n < 3 不再为真，循环终止
```

**注意避免无限循环**：必须保证循环条件最终会变成 `false`，否则循环永不停止。

## label 语句

`label` 提供一个标识符，用于在程序的其他位置引用某个语句（块），常见用途是配合 `break` / `continue` 指明要停止或继续哪一个循环。

语法：

```js
labelName: statement
```

- `labelName` 可以是任何非保留字的标识符；
- `statement` 可以是任意想要标识的语句或语句块。

```js
markLoop:
while (theMark === true) {
  doSomething();
}
```

在多层嵌套循环中，`continue outPoint;` 的作用是跳出当前循环，跳转到被 `outPoint` 标签标记的那层循环继续执行——相比不带标签的写法，跳出和进入的流程更清晰。

## break 语句

用 `break` 终止循环、`switch`，或链接到 `label` 的语句。

- **不带 label**：立即终止当前所在的 `while`、`do...while`、`for` 或 `switch`，控制权交回这些结构后面的语句；
- **带 label**：终止指定的带标记语句。

```js
for (let i = 0; i < a.length; i++) {
  if (a[i] === theValue) {
    break; // 找到目标值，立即结束循环
  }
}
```

## continue 语句

用 `continue` 跳过本次循环的剩余部分，直接进入下一次循环。

- **不带 label**：终止当前 `while`、`do...while` 或 `for` 的本次迭代，继续下一次迭代；
- **带 label**：应用到被该标签标识的循环语句（可从内层循环跳回外层标签处继续）。

```js
// while 示例：i 为 3 时执行 continue，跳过本轮，
// 因此 n 依次取值为 1、3、7、12
```

在嵌套循环中，`continue checkJ` 结束 `checkJ` 的当前迭代并开始下一轮；而 `continue checkIandJ` 则会从外层 `checkIandJ` 语句块的顶部继续执行。

## for...in 语句

`for...in` 用变量循环遍历对象的**所有可枚举属性**，为每个属性执行一次指定的语句。

```js
function showProps(obj, objName) {
  let result = "";
  for (const prop in obj) {
    result += `${objName}.${prop} = ${obj[prop]}\n`;
  }
  return result;
}
// car 有 make 和 model 属性时，输出：
// car.make = Ford
// car.model = Mustang
```

**不要用来遍历数组**：`for...in` 除了数字索引外，还可能遍历到你自定义的属性名。如果给数组添加了属性或方法，`for...in` 迭代的是自定义属性而不是数组元素。遍历数组请使用传统数字索引的 `for` 循环，或 `for...of`、`forEach()`。

## for...of 语句

`for...of` 在**可迭代对象**（`Array`、`Map`、`Set`、`arguments` 等）上创建循环，对值的每个元素调用一次迭代。

`for...in` 与 `for...of` 的核心区别：

```js
const arr = [3, 5, 7];
arr.foo = "hello"; // 自定义属性

for (const i in arr) {
  console.log(i); // "0", "1", "2", "foo" —— 遍历的是索引（含自定义属性名）
}
for (const v of arr) {
  console.log(v); // 3, 5, 7 —— 遍历的是元素的值
}
```

| 语句 | 遍历内容 | 适用对象 |
| --- | --- | --- |
| `for...in` | 可枚举属性名（键/索引） | 普通对象 |
| `for...of` | 元素的值 | 可迭代对象（Array、Map、Set、arguments 等） |

## 速记卡片

| 主题 | 关键结论 |
| --- | --- |
| for 执行顺序 | 初始化 → 判断条件 → 执行循环体 → 更新表达式，循环回条件判断 |
| do...while | 先执行后判断，至少执行一次 |
| while | 先判断后执行，注意避免无限循环 |
| label | 给循环起名，配合 break / continue 精确控制嵌套循环 |
| break | 不带 label 终止当前循环/switch；带 label 终止指定标签语句 |
| continue | 跳过本轮剩余代码，进入下一轮迭代 |
| for...in | 遍历对象可枚举属性，不适合遍历数组 |
| for...of | 遍历可迭代对象的值，遍历数组首选之一 |
