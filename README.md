## 3. 组件库选择

vue3主流组件库：antdv, antdv next,naive ui, element plus.
企业级管理端的话主要考虑antdv和element plus。
naive ui是比较新的框架，UI比较现代。但是长期来看不一定能像antdv和element plus稳定维护。
antdv next是因为ant design一直在迭代而ant design vue却跟不上迭代，于是产生了这个重写的组件库。
调研下来，还是想用antdv next做为主要的UI组件库。

AI建议：针对新手学习，我的建议非常明确：首推 Element Plus，其次 Naive UI，暂时不推荐 Ant Design Vue 作为入门。

所以最终选择：Element Plus
